# aaaboutme

Personal portfolio and about-me website for Brielle Davis.

## Features
- **Profile & Narrative**: Personal introduction, background, and design philosophy.
- **Skills Matrix**: Categorized view of frontend development, UI/UX design, and tooling.
- **Featured Projects**: Filterable project showcase with tech tags and repository links.
- **Milestones / Journey**: Experience timeline and career highlights.
- **Contact & Connect**: Direct messaging form, one-click copy email, and GitHub links.

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```
